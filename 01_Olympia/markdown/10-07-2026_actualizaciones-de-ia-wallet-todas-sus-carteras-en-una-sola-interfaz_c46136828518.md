Actualizaciones de IA Wallet: todas sus carteras en una sola interfaz

Publicado: 10.07.2026

¡Estimados Creadores de Mercado!

Sabemos que utiliza diferentes enfoques para trabajar con IA Wallet. Uno de ellos consiste en utilizar varias billeteras con distintas direcciones.

Esto ofrece diversas ventajas, ya que le permite distribuir sus activos entre diferentes carteras, utilizar cada una para una tarea específica, entre otras posibilidades.

Para que trabajar con varias direcciones sea más cómodo, hemos ampliado las capacidades técnicas de IA Wallet.

Todas sus carteras en una sola interfaz

Ahora puede añadir direcciones de cartera al sistema y visualizarlas como una lista dentro de una única interfaz. Puede cambiar rápidamente entre ellas simplemente seleccionando la correspondiente.

Para añadir una dirección de cartera, haga clic en el botón «ADD WALLET».

A continuación, seleccione la opción de importar una cartera mediante una frase mnemotécnica: «Import using mnemonic phrase».

Después de introducir la frase, la dirección de la cartera estará disponible en la interfaz de su IA Wallet.

Página de configuración actualizada

En la sección «Settings» puede consultar la información de cualquiera de las carteras seleccionadas. Desde allí puede cambiar el nombre de la cartera, restaurar el acceso o eliminarla de la interfaz.

¡IMPORTANTE! En esta página encontrará la opción «Olvidar todas las carteras» («Forget all wallets»). Tenga cuidado: al activar esta función, todas las carteras añadidas se eliminarán de la interfaz de IA Wallet en este navegador. Para volver a agregarlas, deberá introducir la frase mnemotécnica de cada cartera. Utilice esta función con precaución y solo cuando sea realmente necesario.

Aproveche las funciones avanzadas de IA Wallet para optimizar la gestión de sus activos.
