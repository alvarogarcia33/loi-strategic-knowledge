# Reuniones y Conferencias de Presidencia

Esta carpeta está pensada para guardar extractos estratégicos de:

- reuniones privadas o semiprivadas con el presidente
- conferencias internas o cerradas del presidente

Todo lo que se guarde aquí forma parte de la lógica de estudio estratégica y debe considerarse material útil para cruzar con Olympia, GIG-OS y los análisis temáticos.

Los archivos Markdown reales guardados dentro de `reuniones_privadas/` y `conferencias_presidencia/` alimentan automáticamente la sección `Evidencia privada de reuniones` de los dossiers en `09_Analisis_GPT`. Las plantillas, este README y el archivo de ejemplo no se incorporan al análisis.

El objetivo no es solo archivar reuniones: es convertirlas en material útil para que después ChatGPT pueda detectar:

- líneas de tiempo
- cambios de prioridad
- contradicciones con documentos públicos
- proyectos que ganan o pierden centralidad
- señales tempranas de giro estratégico

## Formato recomendado de archivo

Use este patrón de nombre:

`YYYY-MM-DD_tema.md`

Ejemplos:

- `2026-07-01_interatum_y_territoryx.md`
- `2026-07-15_prioridades_hmap.md`
- `2026-08-03_lanzamiento_maestros.md`

## Estructura recomendada de la carpeta

- `reuniones_privadas/`
  Extractos de reuniones privadas o semiprivadas.
- `conferencias_presidencia/`
  Extractos de conferencias, exposiciones o intervenciones más amplias del presidente.
- `README.md`
  Explica el criterio general.
- `TEMPLATE_reunion_presidencia.md`
  Plantilla para reuniones.
- `TEMPLATE_conferencia_presidencia.md`
  Plantilla para conferencias.

## Archivos sugeridos en esta carpeta raíz

- `2026-07-01_ejemplo_formato_reunion.md`
  Ejemplo de cómo documentar una reunión con valor analítico.

## Estructura recomendada

```md
# Título breve de la reunión

- Fecha: 2026-07-01
- Participantes: Presidente, Líder X, Líder Y
- Tema: Interatum y prioridades de despliegue
- Tipo de nota: minuta / resumen / reconstrucción posterior
- Nivel de certeza: alto / medio / bajo

## Resumen

Resumen general de lo hablado.

## Hechos mencionados

- Hecho 1
- Hecho 2

## Puntos estratégicos

- Punto 1
- Punto 2
- Punto 3

## Frases relevantes

- [TEXTUAL] "Frase textual o casi textual 1"
- [PARAFRASIS] Idea recordada con redacción aproximada

## Decisiones o señales de cambio

- Decisión tomada
- Cambio de foco detectado
- Prioridad nueva o desplazada

## Relación con Olympia o GIG-OS

- Coincide con:
- Contradice:
- Amplía:

## Hipótesis de trabajo

- Hipótesis 1
- Hipótesis 2

## Dudas abiertas

- Duda 1
- Duda 2

## Etiquetas sugeridas

- interatum
- territoryx
- hmap
- maestros_del_juego
```

## Recomendaciones

- Separar claramente hechos, interpretación y recuerdos aproximados.
- Si una frase no es textual, marcarla como paráfrasis.
- Si una reunión modifica una línea estratégica anterior, mencionarlo de forma explícita.
- Si una reunión confirma o contradice Olympia o GIG-OS, anotar el cruce.
- Si no está claro el nivel de certeza de una afirmación, indicarlo.
- Conviene mencionar entidades clave siempre con el mismo nombre para facilitar análisis posteriores.
- Si el material proviene de una conferencia, anotar si fue una exposición, una respuesta a preguntas o una intervención breve.
