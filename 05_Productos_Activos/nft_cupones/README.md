# NFT y cupones

Esta carpeta recibira fichas individuales de NFT, cupones y derechos de uso. Cada ficha debe documentar:

- activo que permite obtener o utilizar;
- forma de emision o adquisicion;
- costo evitado o requerido;
- supply anunciado y observado;
- transferibilidad y restricciones;
- utilidad actual y utilidad futura anunciada;
- programa, moneda y producto relacionados;
- fecha y fuente;
- snapshots blockchain vinculados.

Los cupones incluidos inicialmente en H-MAP Industries permanecen descritos en `../productos/HMAP_Industries.md` hasta que se incorporen fuentes individuales adicionales.
