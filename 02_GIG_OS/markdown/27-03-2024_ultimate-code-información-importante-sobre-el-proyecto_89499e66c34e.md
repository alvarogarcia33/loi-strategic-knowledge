# Ultimate Code: información importante sobre el proyecto

Fecha: 27.03.2024
Autor: Redacción de GIG-OS
Categorías: Para la comunidad, Noticias sobre la plataforma, Materiales educativos, Oro, GoalSet Master

¡Estimados/as Socios/as comerciales!

En la conferencia online del 22 de marzo, hablamos de los planes para adaptar las ECN a las condiciones de la blockchain y del metaverso.

Esta estrategia requiere acciones decisivas y oportunas, por lo que hemos lanzado de forma anticipada un programa preferencial para la compra de ECN.

En el marco del programa, ustedes tienen acceso al Ultimate Code, un código especial que ofrece ventajas especiales en la adquisición de ECN.

El proyecto adquiere aún más importancia debido a los próximos desarrollos relacionados con el programa GOS Hold.

El tiempo es esencial en este asunto, por lo que queríamos ofrecerles esta oportunidad lo antes posible. La alta intensidad del trabajo ha llevado a un error en la descripción del programa Ultimate Code en la plataforma online.

La imprecisión ha sido detectada y se corregirá el 28 de marzo de 2024.

Aquí tienen la información exacta sobre los principios de funcionamiento del Ultimate Code:

Todos los contratos de compra de ECN firmados durante el período de vigencia del Ultimate Code activado tendrán las siguientes características:

1. El precio de ECN se reduce a la mitad.

2. El pago de TODOS los contratos se transfiere a GOS Hold.

3. Si el pago se realiza con bonos, estos se recalculan en GOS Coin y se colocan en GOS Hold.

Les recordamos una vez más: el pago de TODOS los contratos concluidos utilizando Ultimate Code se transfiere a GOS Hold.
