# Ultimate Code: oferta especial para Socios comerciales

Fecha: 24.04.2024
Autor: Redacción de GIG-OS
Categorías: Para la comunidad, Noticias sobre la plataforma, Materiales educativos, Oro, GoalSet Master

¡Estimados/as Socios/as comerciales!

Les recordamos que en el marco del programa de compra de ECN en condiciones ventajosas, a todos los Socios comerciales se les han acreditado 5 Ultimate Code, cuya activación otorga privilegios especiales.

¡Ultimate Code es la última oportunidad para convertirse en un titular de ECN!

El período de validez del Ultimate Code es de 30 días desde el momento de la activación. Durante este tiempo, todos los Socios comerciales que firmen contratos recibirán los siguientes beneficios:

1. El precio de ECN se reduce a la mitad.

2. El pago de todos los contratos se transfiere a GOS Hold.

3. Si el pago se realiza con bonos, éstos se convierten en GOS Coin y se colocan en GOS Hold.

Atención: al activar Ultimate Code, ustedes pueden firmar cualquier número de contratos de compra de ECN hasta que expire la activación.
