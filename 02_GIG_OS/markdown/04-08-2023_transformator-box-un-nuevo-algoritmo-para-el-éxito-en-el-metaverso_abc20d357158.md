# TRANSFORMATOR BOX: un nuevo algoritmo para el éxito en el metaverso

Fecha: 04.08.2023
Autor: Redacción de GIG-OS
Categorías: Para la comunidad, Noticias sobre la plataforma, Materiales educativos, Oro, GoalSet Master

¡Queridos/as amigos/as!

En la plataforma online, en el modo de prueba, se ha lanzado un nuevo algoritmo de interacción en las estructuras:

TRANSFORMATOR BOX

El mundo del metaverso y del blockchain requiere una gran cantidad de nuevas soluciones tecnológicas. Se necesitan fórmulas que permitan realizar tareas complejas de forma rápida y con el máximo beneficio para los ciudadanos de Global Metaverse.

TRANSFORMATOR BOX es una solución avanzada para los negocios en el entorno digital. Con este algoritmo, pueden transformar la actividad de su estructura en activos valiosos.

¿Cómo funciona?

TRANSFORMATOR BOX consta de 10 ranuras, que se completan con fichas POINT BOX. Las fichas se generan cada vez que alguien en los diez niveles inferiores de la estructura recibe un NFT o UTT. En este caso, se entrega una ficha POINT BOX a cada Líder de la línea ascendente en los diez niveles superiores recibe.

Por lo tanto, un NFT/UTT puede traer 10 fichas: una para cada una de las diez de las personas de la línea ascendente si tienen un TRANSFORMATOR BOX.

¿Cómo obtener TRANSFORMATOR BOX?

TRANSFORMATOR BOX vale 1 GICO Coin.

Importante: ¡la compra está disponible solo hasta el 19 de octubre de 2023 a las 12:00 CET!

Si el TRANSFORMATOR BOX está completado, se necesita un TRANSFORMATOR BOX nuevo para seguir recibiendo fichas. De lo contrario, todas las fichas obtenidas posteriormente se perderán.

Para evitar la pérdida de fichas, pueden utilizar la opción de compra por paquetes. Esta opción les permite tener hasta seis TRANSFORMATOR BOX al mismo tiempo.

En el caso de la compra por paquetes, el coste de cada TRANSFORMATOR BOX que compre depende del número ordinal en la fila del TRANSFORMATOR BOX sin completar el qué tendrá el TRANSFORMATOR BOX que compre:

Ejemplo 1

Un participante compra 1 TRANSFORMATOR BOX con 1 GICO Coin. Espera a que se complete con 10 fichas POINT BOX. Compra el siguiente TRANSFORMATOR BOX con 1 GICO Coin. Y así sucesivamente: completa — compra.

Ejemplo 2

Un participante compra 1 TRANSFORMATOR BOX con 1 GICO Coin y, para no perder fichas POINT BOX, compra otro TRANSFORMATOR BOX con 5 GICO Coin. Una vez completados los dos TRANSFORMATOR BOX, el participante compra el siguiente con 1 GICO Coin.

Ejemplo 3

Un participante compra 1 TRANSFORMATOR BOX con 1 GICO Coin y, para no perder fichas POINT BOX, compra otro TRANSFORMATOR BOX con 5 GICO Coin. Después de completar el primer TRANSFORMATOR BOX, el participante decide seguir un paso por delante y compra el siguiente TRANSFORMATOR BOX con 5 GICO Coin, ya que solo le quedaba un TRANSFORMATOR BOX sin completar.

Ejemplo 4

Un participante compra 1 TRANSFORMATOR BOX con 1 GICO Coin y, para no perder fichas POINT BOX, compra otro TRANSFORMATOR BOX con 5 GICO Coin. Y uno más con 10 GICO Coin. Después de completar el primer TRANSFORMATOR BOX, y de quedarse con dos TRANSFORMATOR BOX sin completar, el participante decide seguir un paso por delante y compra el siguiente TRANSFORMATOR BOX con 10 GICO Coin, ya que le quedaban dos TRANSFORMATOR BOX sin completar.
