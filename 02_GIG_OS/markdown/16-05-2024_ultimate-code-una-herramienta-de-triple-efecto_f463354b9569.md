# Ultimate Code: una herramienta de triple efecto

Fecha: 16.05.2024
Autor: Redacción de GIG-OS
Categorías: Para la comunidad, Noticias sobre la plataforma, Materiales educativos, Oro, GoalSet Master

¡Estimados/as Socios/as comerciales!

La plataforma online sigue ofreciendo un programa preferencial de compra de ECN.

Les recordamos que en el marco del programa a todos los Socios comerciales se les han acreditado 5 Ultimate Code. Cada código activado les permite adquirir ECN en condiciones especialmente favorables.

Además, el uso de Ultimate Code les reportará beneficios tangibles en los programas GOS Hold y HoldAmp.

Así es como funciona:

Ustedes activan el Ultimate Code y, en los 30 días siguientes a la activación, firman cualquier número de contratos de compra de ECN. Al utilizar el código, el precio de ECN se reduce a la mitad.

El pago de todos los contratos se transfiere a GOS Hold. Si el pago se realiza con bonos, estos se convierten en GOS Coin y se colocan en GOS Hold. De este modo, ustedes no pierden sus monedas, sino que las reservan en el programa GOS Hold durante 3 años.

Cada GOS Coin transferida a GOS Hold les da derecho a recibir 1 SHORT Coin según las condiciones del programa HoldAmp. Pueden cambiar SHORT Coin por MINER'S Coin o tokens técnicos UTT para todos los boards de System Transformator.

Utilicen el Ultimate Code y obtengan un triple beneficio:

✔ compren ECN a un precio especial;

✔ repongan sus activos en GOS Hold;

✔ amplíen sus oportunidades en el programa HoldAmp.
