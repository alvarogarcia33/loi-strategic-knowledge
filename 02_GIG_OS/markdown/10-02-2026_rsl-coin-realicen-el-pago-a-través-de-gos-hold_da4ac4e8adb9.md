# RSL Coin: realicen el pago a través de GOS Hold

Fecha: 10.02.2026
Autor: Redacción de GIG-OS
Categorías: Para la comunidad, Noticias sobre la plataforma, Materiales educativos, Oro, GoalSet Master

Las tarifas de servicio ahora se pueden pagar a plazos utilizando tokens GOS Hold.

De esta manera, pueden utilizar los fondos de GOS Hold sin esperar a que expire el período de reserva.

Se acepta cualquier GOS Hold Token para el pago. Pueden utilizarlos para pagar la tarifa de servicio completa de una sola vez o realizar pagos a plazos.

Tengan en cuenta: si han elegido pagar la tarifa de servicio a plazos, ahora pueden realizar pagos parciales tanto con GOS Hold Token como con el método estándar, usando monedas GOS Coin.

Si el GOS Hold Token que utilizan para el pago contiene más monedas de las necesarias, solo se descontará la cantidad requerida de GOS Coin. Las monedas restantes, no utilizadas para el pago, permanecerán en este token.

Ejemplo

Desean pagar la tarifa de servicio con un token GOS Hold que contiene 8 GOS Coin.

Se descontarán 5 GOS Coin del token (el importe de la tarifa de servicio), y les quedará un GOS Hold Token que contiene 3 GOS Coin.

¡Aprovechen esta oportunidad para convertirse en propietarios completos de RSL Coin lo antes posible!
