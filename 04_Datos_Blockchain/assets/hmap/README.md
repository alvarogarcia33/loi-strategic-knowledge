# HMAP Coin

Snapshots fechados de la distribucion de HMAP Coin observada en blockchain.

## Regla de interpretacion

- El archivo original y su hash son la evidencia primaria.
- Una wallet no equivale necesariamente a una persona.
- La titularidad de la wallet corporativa esta pendiente de confirmacion para este activo.
- Hasta confirmarla, ninguna wallet se excluye de las metricas de distribucion.
- El valor de 50 EUR por HMAP fue aportado por el usuario como contexto economico; no fue deducido del archivo blockchain.

## Uso temporal

Cada nuevo escaneo debe conservar la fecha en el nombre. Con dos o mas fechas se podran medir cambios de balances, wallets nuevas, concentracion y ritmo de movimiento, sin interpretar automaticamente cada transferencia como compra.
